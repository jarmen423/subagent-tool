# Cursor Sub-Agent v0.2 Summary

## What's new

- **NATS event bus** — Python daemon publishes session/wave events to NATS subjects
- **Rust gateway** (`subagent-gateway`) — WebSocket bridge using nats.rs + axum
- **`cursor-subagent bus start|stop|status`** — manages nats-server + gateway
- **`resume` CLI/API** — re-register sessions from Cursor agent IDs
- **`spawn --from-template`** — replay persisted automation sessions
- **Graceful daemon shutdown** — `POST /shutdown` before process kill on Windows
- **FastAPI WebSocket removed** — use gateway for `watch`
- **Repo `.env` loading** — `CURSOR_API_KEY` resolved from `--cwd` (walks to repo root)
- **Windows bridge bootstrap** — pre-launches cursor-sdk bridge (fixes `WinError 10038`)
- **Daemon REST app restored** — `app.py` was accidentally empty in initial v0.2 commit
- **Z.AI Coding Plan provider** — `zai-coding-plan` provider with OpenAI-compatible streaming; uses `ZAI_API_KEY` and defaults to `glm-5.1`

## Stack

```
CLI --REST--> cursor-subagentd (Python) --publish--> nats-server
CLI --WS----> subagent-gateway (Rust) <--subscribe-- nats-server
```

## Quick start

```bash
pip install -e ".[dev]"
powershell -File scripts/install-nats-server.ps1
cargo build --release -p subagent-gateway
# CURSOR_API_KEY in repo .env or ~/.cursor/subagents/.env
cursor-subagent bus start
cursor-subagent spawn --task "Reply ok" --cwd . --json
python scripts/hello_subagent.py   # after smoke-test spawn
```

## Tests

- Unit: `python -m pytest -q` (includes env + session manager tests)
- Integration: `python -m pytest -q -m integration` (requires `bus start`)
